# 🔎 User Finder

A simple JavaScript project where you can search for a user by **first name or last name** and view their information in a card.

## ✨ What it does

* Search by first or last name
* Shows the user's profile picture
* Shows their job
* Shows their location
* Copy names with one click
* Gets real user data from an API
